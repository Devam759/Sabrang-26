## Preparing the files

- **Portrait and landscape both work.** Each photograph is sized from its own
  aspect ratio in 3D, so nothing is stretched. A mix reads better than a set
  that is all one shape.
- **Around 1200px on the long edge is plenty.** These become GPU textures at
  roughly a third of the screen; larger files cost memory for no visible gain.
- **Keep each file under ~300KB.** Sixteen photographs load together.
- **Dark, high-contrast frames suit the space best** — the gallery sits in a
  near-black chamber, and washed-out images lose their edges against it.
